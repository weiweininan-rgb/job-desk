# 第一版发布检查

- [ ] 以 release:prepare 导出的干净文件创建新仓库，不携带私人 Git 历史。
- [ ] 人工检查源码、发布包与第三方声明，没有个人数据、工作表标识、密钥或无权再发布的素材。
- [ ] npm ci、lint、test、test:schema、build 通过，记录 npm audit 剩余风险。
- [ ] 全新 Supabase 项目按部署文档初始化；唯一账号可登录，后端公开注册已关闭。
- [ ] GitHub Pages 在项目子路径部署成功；刷新与 Hash 路由正常。
- [ ] 手动添加默认当天，编辑/刷新后数据正确。
- [ ] Excel 模板导入，默认全部方向；设置关键词后过滤正确，优先城市与大厂标注正确。
- [ ] 来源岗位“去投递→确认”只生成一条跟踪记录，日期为上海时区当天；重复确认不重复生成。
- [ ] 看板每列独立滚动；放弃当前记录后灰显置底，恢复后保留原阶段。
- [ ] 流程新增/编辑、截止提醒、日历、统计、CSV 和测试记录删除均正常。
- [ ] 未登录及不同测试账号不能读取、修改或删除另一账号数据；飞书令牌表不能由前端读取。
- [ ] 不启用飞书时核心流程不请求飞书函数。若启用，完成本人 OAuth 和真实同步，错误信息可定位。

本地隔离 PostgreSQL 测试不能证明 Supabase Auth、PostgREST、托管权限和真实浏览器端到端通过。未完成云端验收的包只能叫候选版本，不标记稳定发布。
